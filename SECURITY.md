# Security Policy

## Reporting a vulnerability

If you discover a security issue in this plugin, please **do not** open a public GitHub issue with exploit details.

Instead, report it privately using one of the following channels:

- [GitHub Security Advisories](https://github.com/tetsuo13/Roundcube-Matomo-Tracking-Api-Plugin/security/advisories/new) (preferred)
- Repo maintainers

Please include:

- A description of the issue and its impact
- Steps to reproduce
- Affected versions (Roundcube, plugin, PHP)
- A proof of concept or patch, if available
